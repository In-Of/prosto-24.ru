# prosto-24.ru

Сайт Просто24 — своя CRM за 24 часа. Статический, публикуется через GitHub Pages из ветки `main`.

## Блог
Jekyll (встроен в GitHub Pages). Статьи — `_posts/ГГГГ-ММ-ДД-slug.md` с front matter `title`, `description`
(при необходимости `slug`). Адрес: `/blog/slug/`. Главная и `/hosting/` — обычный HTML без front matter, Jekyll копирует их как есть.
